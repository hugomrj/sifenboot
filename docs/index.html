Sifenboot

Middleware de alto rendimiento para SIFEN (Paraguay).

Descripción General

Integración Open Source de alto rendimiento basada en Spring Boot 3.4.0 y Undertow optimizado para el uso nativo de Virtual Threads (Java 21) interactuando eficientemente con los esquemas SOAP de SIFEN.

Core Stack

  • Spring Boot 3.4.0
  • Java 21 (Virtual Threads)
  • Undertow Server
  • PostgreSQL 15+
