Inicialización de Base de Datos

Soporte técnico para el despliegue del esquema de datos persistente en entornos Windows.

1. Variables de Entorno en PowerShell

$env:DB_HOST="localhost"
$env:DB_PORT="5432"
$env:DB_NAME="sifenboot"
$env:DB_USER="postgres"
$env:DB_PASS="su_password"

2. Ejecución del Módulo Setup

Ejecute el aprovisionamiento de las tablas del sistema y el diccionario geográfico (Departamentos, Distritos, Localidades):

.\mvnw.cmd compile exec:java "-Dexec.mainClass=org.sifenboot.setup.SetupDatabase"

3. Compilación de Producción

.\mvnw.cmd clean package
java -jar target\sifenboot-api-1.0.0-SNAPSHOT.jar
