Sifenboot

Middleware de alto rendimiento para SIFEN (Paraguay).

Referencia de la API

POST /api/empresa/{emisor}/factura/registrar

Permite registrar y emitir una nueva factura electrónica enviando los datos estructurados del receptor y el detalle de ítems.

Parámetros de Ruta

Parámetro Tipo Descripción
emisor string Identificador del emisor configurado en el sistema.

Headers

Header Tipo Descripción
X-API-KEY string Token de autenticación requerido para consumir la API.

Campos del Body

Campo Tipo Descripción
establecimiento number Código de establecimiento asignado por la SET.
punto_expedicion number Punto de expedición operativo.
numero_documento number Número secuencial del documento.
codigo_seguridad (Opcional) string Código de seguridad utilizado para la generación del documento electrónico. Si no se envía, el sistema generará automáticamente un valor válido.
items array Lista de productos o servicios incluidos.
